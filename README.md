# RapidResQ

A roadside emergency assistance platform that connects vehicle users with nearby service centers. The system uses geolocation and dispatch logic to help route assistance requests efficiently.

## Features

- User and service-center workflows
- Real-time location capture with the Geolocation API
- Emergency assistance request and dispatch flow
- Role-based access control for admin workflows
- MySQL database optimization

## Tech Stack

- PHP
- MySQL
- jQuery
- HTML/CSS
- REST APIs
- Geolocation API

## Setup

1. Clone this repository.
2. Import the project database into MySQL.
3. Update the database credentials in the project configuration.
4. Run the project on a local PHP server such as XAMPP.
5. Open the application in your browser.
